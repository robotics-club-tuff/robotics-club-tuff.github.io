FTC Biobuzz Guide

An unofficial guide based on my experience with the FTC Biobuzz basebot!

Getting Started

If you think the coding section of FTC may seem daunting, you aren't alone.
Luckily, FTC has a detailed documentation website all over the coding section. It is encouraged you follow the official guide and use this one as a secondary resource or overview.

First, plug in the robot's battery into the control hub, and press the black button to turn on the wifi signal.



Then decide what major programming platform you will use:

Block Coding - Easiest setup and the simplest programming. Simply type "192.168.43.1:8080" into your browser once connected to the robot for the program and manage site.



Onbot Java - Located in the program and manage website, this is a compromise, with most of the robustness of Android Studio and lessened complexity.



Android Studio - Intended for advanced users; this allows you to sync a project via git, save previous versions or "commits," and host a github repository, among other advanced features.

AprilTag Guide

AprilTags are visual markers with unique IDs - similar to a QR code. A robot’s vision software can use a detected tag, along with camera and tag-size information, to estimate its position and orientation. An AprilTag detector is essential for the Biobuzz competition.
